1) ex_home_main.jsp
The main page featuring "Login" and "Sign Up" buttons.
Displays other users' profiles; users must register to access the main content.
2) ex_login.jsp
Login page with input fields for ID and password.
Submits form data to ex_login_result.jsp.
3) ex_login_result.jsp
Checks user credentials against the database.
If login is successful, the session is established.
4) ex_regist.jsp (Sign-Up Page)
Fields:
ID: Must be at least 6 characters; duplicate check required.
Password: Must match confirmation.
Address: Optional.
Nickname: Mandatory.
Native Language: Choose from 8 available languages.
Exchange Language: Choose from 8 available languages.
Preferred Study Time: User selects availability.
Self-Introduction: Optional.
Profile Picture: Upload (allowed formats: jpg, jpeg, png, gif).
5) ex_id_duplicate.jsp
Checks if a username is already taken and returns a flag indicating availability.
6) ex_regist_insert.jsp
Handles sign-up form submission.
Processes file uploads:
If a duplicate file name exists, an index is added for uniqueness.
Stores uploaded images in a server directory and saves their paths in the database (TBL_EUSER).
7) ex_header.jsp
Contains logo, logout button, profile update link, and navigation menu.
Clicking the logo redirects to ex_main.jsp after login.
8) ex_footer.jsp
Static footer with possible links to Facebook, Instagram, and Twitter.
9) ex_main.jsp (Main Page after Login)
Displays registered users’ profiles.
Users can filter profiles by preferred language and study time.
Each profile includes a "Request" button to send a connection request.
Clicking "Request" sends the target user’s ID to ex-apply-result.jsp.
10) ex-apply-result.jsp
Inserts a request record into TBL_APPLY.
Stores both requester and recipient IDs.
11) ex_border.jsp (Community Board & Language Exchange Requests)
Users can post under different categories (general discussion or language exchange).
Clicking a post title redirects to ex-border-contents.jsp.
12) ex-border-insert.jsp
Page to create a new post with title, category, and content.
Enforces non-empty fields.
Submits form to ex-border-insert-result.jsp.
13) ex-border-insert-result.jsp
Inserts post data into TBL_EBOARD.
BOARDNO is auto-incremented using a database trigger.
Stores the session user’s ID as the post author.
14) ex-border-contents.jsp
Displays a post’s content.
If the category is "Language Exchange," a "Request" button is available (works like ex-apply-result.jsp).
If the user is the author or an admin, they can edit or delete the post.
15) ex-border-update.jsp
Allows post editing, pre-filling the existing content.
Clicking "Cancel" uses window.history.back().
Clicking "Update" submits to ex-border-update-result.jsp.
16) ex-border-update-result.jsp
Processes the post update.
17) ex-border-delete.jsp
Deletes the post from the database.
18) ex_applyList.jsp
Displays:
Received requests (with "Approve" button, but no functionality).
Sent requests (with "Cancel" button).
Clicking "Cancel" sends data to ex-apply-delete.jsp.
19) ex-apply-delete.jsp
Deletes the request record.
20) ex_f&q.jsp (FAQ Page)
Admins can add new FAQs.
FAQs are categorized as "Notices" or "FAQs."
Clicking a title opens ex_f&q_contents.jsp.
"Create" button redirects to ex_f&q_insert.jsp.
21) ex_f&q_insert.jsp
Admin-only page for adding FAQs.
Clicking "Submit" validates input and sends data to ex_f&q_insert_result.jsp.
22) ex_f&q_insert_result.jsp
Inserts a new FAQ into TBL_EFQ.
23) ex_f&q_contents.jsp
Displays FAQ details.
Admins can edit or delete posts.
24) ex_f&q_delete.jsp
Deletes an FAQ post.
25) ex_f&q_update.jsp
Allows admins to edit FAQs.
Clicking "Update" submits to ex-border-update-result.jsp.
26) ex_info_update.jsp
Users can update their profile information (except ID and password).
27) Miscellaneous
ex-db.jsp: Contains database connection details.
WEB-INF/lib/ojdbc8.jar: Oracle database connection library.
